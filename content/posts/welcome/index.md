# 为什么建立这个知识库

这个博客用于持续沉淀 Agent、Harness、LLM 相关知识，把零散的阅读、实践和思考整理成可检索、可复用的文章。

## 内容组织

| 分类 | 关注主题 |
|---|---|
| Agent | Agent 架构、规划、工具调用、记忆与多 Agent |
| Harness | 上下文管理、工具系统、执行循环、状态与安全 |
| LLM | 模型原理、提示词、推理、评测与部署 |
| 工程实践 | 开发环境、自动化、项目实践与复盘 |

## 写作约定

- 一篇文章尽量聚焦一个明确问题。
- 区分原始资料、个人理解和工程验证结果。
- 记录关键结论，也保留必要的上下文与来源。
- 对尚未验证的内容明确标注，不把推测写成事实。

后续文章会逐步补充。你可以通过顶部的搜索、分类和标签查找内容。
